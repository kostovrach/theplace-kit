# Slugify

Утилита для преобразования строки в URL-friendly slug с транслитерацией кириллицы в латиницу.

## Назначение

Используется для генерации человеко-читаемых URL-идентификаторов, например:

- URL страниц
- slug для CMS-объектов
- якорей и идентификаторов

## Функционал

- Транслитерация кириллицы
- Приводит строку к lowercase
- Удаляет диакритику (accent marks)
- Убирает спецсимволы
- Заменяет пробелы на дефисы
- Схлопывает повторяющиеся дефисы
- Подходит для SEO-friendly URL

## Поддержка транслитерации

Примеры преобразования:

| Символ | Результат |
| ------ | --------- |
| ж      | zh        |
| ч      | ch        |
| ш      | sh        |
| щ      | sch       |
| ю      | yu        |
| я      | ya        |

## Аргументы

| Параметр | Тип                | Описание                          |
| -------- | ------------------ | --------------------------------- |
| `text`   | `string \| number` | Входная строка для преобразования |

## Возвращаемое значение

| Тип      | Описание    |
| -------- | ----------- |
| `string` | slug-строка |

## Пример использования

```ts
slugify('Привет мир');
// -> "privet-mir"

slugify('Тестовая статья №1');
// -> "testovaya-statya-1"
```
