# Theplace-kit <br> IsChromium

Утилита для определения, запущен ли браузер на Chromium-движке.

## Назначение

Позволяет определить, использует ли браузер Chromium (Chrome, Edge, Opera и другие производные).  
Применяется для условной логики: применение специфических стилей, полифилов, WebGL-оптимизаций или обхода браузерных багов.

## Функционал

- Анализирует `navigator.userAgent`
- Возвращает `true` для Chrome, Edge, Opera и других Chromium-based браузеров
- Лёгкая и быстрая проверка (без тяжёлых библиотек)

## Аргументы

Функция не принимает параметров.

## Возвращаемое значение

| Тип        | Описание                                      |
| ---------- | --------------------------------------------- |
| `boolean`  | `true` — если браузер на базе Chromium        |

## Пример использования

```ts
if (isChromium()) {
    // ... какие то специфические вещи только для chromium
}
```

```vue
<!-- В шаблоне -->
<template>
  <div v-if="isChromium()">Chromium-based браузер</div>
</template>
```
