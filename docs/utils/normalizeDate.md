# NormalizeDate

Утилита для форматирования даты в человеко-читаемый русский формат.

## Назначение

Преобразует строку даты (ISO или любой формат, распознаваемый `Date`) в удобный для пользователя вид: «15 апреля 2026». Используется в карточках новостей, событиях, заказах, профилях и других местах, где нужна красивая дата.

## Функционал

- Использует встроенный `toLocaleDateString` с локалью `ru-RU`
- Выводит день (две цифры), полное название месяца и год
- Корректно работает с большинством входных форматов дат

## Аргументы

| Параметр  | Тип      | Описание                             |
| --------- | -------- | ------------------------------------ |
| `dateStr` | `string` | Строка с датой (ISO или совместимая) |

## Возвращаемое значение

| Тип      | Описание                                           |
| -------- | -------------------------------------------------- |
| `string` | Отформатированная дата (например `15 апреля 2026`) |

## Пример использования

```ts
normalizeDate('2026-04-15');
// -> "15 апреля 2026"

normalizeDate('2026-04-15T12:30:00.000Z');
// -> "15 апреля 2026"

normalizeDate('2025-12-31');
// -> "31 декабря 2025"
```
