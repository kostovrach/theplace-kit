# PartialHiddenPhone

Утилита для частичного скрытия номера телефона (маскирования отдельных цифр).

## Назначение

Используется для безопасного отображения номеров телефонов в интерфейсе: в личном кабинете, списках заказов, профилях и т.д., чтобы не показывать полный номер.

## Функционал

- Принимает номер как строку или число
- Заменяет указанные позиции на символ-маскировку (по умолчанию `*`)
- Не ломает короткие номера
- Не мутирует исходные данные

## Аргументы

| Параметр      | Тип                | По умолчанию        | Описание                                         |
| ------------- | ------------------ | ------------------- | ------------------------------------------------ |
| `phone`       | `string \| number` | —                   | Номер телефона                                   |
| `positions`   | `number[]`         | `[5, 6, 9, 10, 11]` | Индексы символов, которые нужно скрыть (0-based) |
| `replacement` | `string`           | `"*"`               | Символ замены                                    |

## Возвращаемое значение

| Тип      | Описание                                  |
| -------- | ----------------------------------------- |
| `string` | Номер телефона с замаскированными цифрами |

## Пример использования

```ts
partialHiddenPhone('79161234567');
// -> "79161**45**"   (скрыты позиции 5,6,9,10,11)

partialHiddenPhone(79161234567, [4, 5, 6, 7]);
// -> "7916****4567"

partialHiddenPhone('+7 (916) 123-45-67', [7, 8, 9, 11, 12, 13], '•');
// -> "+7 (916) •••-••-67"
```
