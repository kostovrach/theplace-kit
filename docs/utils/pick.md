# Theplace-kit <br> Pick

Утилита для создания нового объекта, содержащего **только** указанные ключи.  
Типизированный аналог `lodash.pick`.

## Назначение

Используется для выборки нужных полей из объектов — особенно удобно при формировании ответов API, подготовке данных для клиента, фильтрации больших объектов и создании «лёгких» версий сущностей.

## Функционал

- Создаёт **новый** объект (исходный не мутируется)
- Полная поддержка TypeScript — возвращает корректный тип `Pick<T, K>`
- Работает с любыми объектами
- Поддерживает массив ключей

## Аргументы

| Параметр | Тип                        | Описание                              |
| -------- | -------------------------- | ------------------------------------- |
| `obj`    | `T`                        | Исходный объект                       |
| `keys`   | `(keyof T)[]`              | Массив ключей, которые нужно оставить |

## Возвращаемое значение

| Тип          | Описание                          |
| ------------ | --------------------------------- |
| `Pick<T, K>` | Новый объект только с выбранными ключами |

## Пример использования

```ts
interface User {
  id: string;
  name: string;
  email: string;
  password: string;
  role: 'admin' | 'user';
  createdAt: Date;
}

const user: User = {
  id: "1",
  name: "Иван Иванович",
  email: "ivan@example.com",
  password: "secret123",
  role: "user",
  createdAt: new Date()
};

// Выбираем только публичные поля
const publicUser = pick(user, ["id", "name", "email"]);

// Результат:
// {
//   id: "1",
//   name: "Иван Иванович",
//   email: "ivan@example.com"
// }

// Можно использовать для нескольких выборок
const credentials = pick(user, ["email", "password"]);
```
