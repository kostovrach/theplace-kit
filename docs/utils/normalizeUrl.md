# NormalizeUrl

Утилита для извлечения корневого домена (hostname) из URL-строки.

## Назначение

Приводит любой URL (с протоколом, портом, путём, query-параметрами) к чистому доменному имени.  
Используется для нормализации ссылок, сравнения доменов, формирования CORS-политик, работы с реферерами и т.д.

## Функционал

- Поддерживает URL с протоколом и без него
- Убирает порт, путь, query и фрагмент
- Использует нативный `URL` парсер (с fallback для некорректных строк)
- Возвращает пустую строку при некорректном/пустом входе
- Безопасен и устойчив к ошибкам

## Аргументы

| Параметр | Тип      | Описание                          |
| -------- | -------- | --------------------------------- |
| `input`  | `string` | URL-строка (полная или частичная) |

## Возвращаемое значение

| Тип      | Описание                |
| -------- | ----------------------- |
| `string` | Корневой домен или `''` |

## Пример использования

```ts
normalizeUrl('https://example.com:3000/some/path?query=1#hash');
// -> "example.com"

normalizeUrl('http://sub.domain.co.uk');
// -> "sub.domain.co.uk"

normalizeUrl('domain.ru');
// -> "domain.ru"

normalizeUrl('https://localhost:3000');
// -> "localhost"

normalizeUrl('not-a-url');
// -> ""
```
