# Theplace-kit <br> Logger

Утилита для унифицированного логирования с автоматической временной меткой.

## Назначение

Предоставляет единый удобный способ логирования с префиксом и точным временем вызова. Используется для отладки, мониторинга server API, composables и ключевых процессов приложения.

## Функционал

- Добавляет timestamp в формате `YYYY-MM-DD HH:mm:ss`
- Обновляет время только один раз в секунду (кэширование для производительности)
- Поддерживает любое количество аргументов (`...args`)
- Является обёрткой над `console.log`
- Работает как в браузере, так и на сервере (зачем логировать что-то в браузер, остается открытым вопросом)

## Аргументы

| Параметр  | Тип         | Описание                                        |
| --------- | ----------- | ----------------------------------------------- |
| `prefix`  | `string`    | Префикс лога (например `DEBUG`, `ERROR`, `API`) |
| `...args` | `unknown[]` | Любые данные для вывода в консоль               |

## Возвращаемое значение

Функция ничего не возвращает (`void`).

## Пример использования

```ts
logger('DEBUG', 'content loaded', { id: 123, title: 'Test' });
// → [2026-05-12 14:32:11] DEBUG: content loaded { id: 123, title: 'Test' }

logger('ERROR', 'Failed to fetch data', error);

logger('API', 'Request to /api/cms/pages', { status: 200, duration: '45ms' });
```
