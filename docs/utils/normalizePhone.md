# Theplace-kit <br> NormalizePhone

Утилита для нормализации номеров телефонов в единый формат.

## Назначение

Приводит телефонные номера из различных форматов (с пробелами, скобками, дефисами, +7 или 8) к единому виду `7XXXXXXXXXX`. Используется при сохранении в CMS, валидации форм, отправке SMS и т.д.

## Функционал

- Убирает все нецифровые символы
- Приводит номера, начинающиеся с `8`, к формату с `7`
- Добавляет `7` для 10-значных номеров
- Выбрасывает ошибку при невалидном номере
- Работает как со строками, так и с числами

## Аргументы

| Параметр | Тип                | Описание                              |
| -------- | ------------------ | ------------------------------------- |
| `raw`    | `string \| number` | Номер телефона в любом формате        |

## Возвращаемое значение

| Тип      | Описание                                      |
| -------- | --------------------------------------------- |
| `string` | Нормализованный номер в формате `7XXXXXXXXXX` |

## Пример использования

```ts
normalizePhone("+7 (916) 123-45-67");
// -> "79161234567"

normalizePhone("8 (495) 777-88-99");
// -> "74957778899"

normalizePhone(9161234567);
// -> "79161234567"

normalizePhone("+79161234567");
// -> "79161234567"

```
