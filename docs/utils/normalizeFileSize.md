# NormalizeFileSize

Утилита для преобразования размера файла из байтов в человеко-читаемый формат.

## Назначение

Преобразует количество байт в удобный для пользователя вид (например, `1.5 MB`, `2.3 GB`). Используется при отображении размеров файлов, лимитов загрузки, в карточках документов и т.д.

## Функционал

- Поддержка двух систем счисления: **SI** (1000, десятичная) и **IEC** (1024, двоичная)
- По умолчанию использует SI (`kB`, `MB`, `GB`)
- Округляет до одной цифры после запятой
- Корректно обрабатывает невалидные значения (возвращает `0 kB`)
- Работает со строками и числами

## Аргументы

| Параметр | Тип                | По умолчанию | Описание                          |
| -------- | ------------------ | ------------ | --------------------------------- |
| `raw`    | `string \| number` | —            | Размер файла в байтах             |
| `base`   | `'SI' \| 'IEC'`    | `'SI'`       | Система измерения (1000 или 1024) |

## Возвращаемое значение

| Тип      | Описание                                   |
| -------- | ------------------------------------------ |
| `string` | Форматированный размер (например `2.4 MB`) |

## Пример использования

```ts
normalizeFileSize(1_572_864);
// -> "1.6 MB"

normalizeFileSize(1_572_864, 'IEC');
// -> "1.5 MiB"  (использует 1024)

normalizeFileSize(4_294_967_296);
// -> "4.3 GB"

normalizeFileSize(512);
// -> "0.5 kB"

normalizeFileSize('invalid');
// -> "0 kB"

normalizeFileSize(-100);
// -> "0 kB"
```
