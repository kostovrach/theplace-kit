# Omit

Утилита для создания нового объекта без указанных ключей.  
Типизированный аналог `lodash.omit`.

## Назначение

Используется для безопасного удаления чувствительных или служебных полей из объектов (например, `password`, `token`, внутренних `_id` и т.д.) перед отправкой данных на клиент, в API-ответы или при логировании.

## Функционал

- Создаёт **новый** объект (исходный не мутируется)
- Полная поддержка TypeScript — возвращает корректный тип `Omit<T, K>`
- Работает с любыми объектами
- Поддерживает массив ключей (включая `readonly`)

## Аргументы

| Параметр | Тип                    | Описание                             |
| -------- | ---------------------- | ------------------------------------ |
| `obj`    | `T`                    | Исходный объект                      |
| `keys`   | `readonly (keyof T)[]` | Массив ключей, которые нужно удалить |

## Возвращаемое значение

| Тип          | Описание                          |
| ------------ | --------------------------------- |
| `Omit<T, K>` | Новый объект без указанных ключей |

## Пример использования

```ts
interface User {
	id: string;
	name: string;
	email: string;
	password: string;
	role: 'admin' | 'user';
}

const user: User = {
	id: '1',
	name: 'Иван Иванович',
	email: 'ivan@example.com',
	password: 'secret123',
	role: 'user',
};

// Убираем чувствительные данные
const safeUser = omit(user, ['password']);

// Результат:
// {
//   id: "1",
//   name: "Иван Иванович",
//   email: "ivan@example.com",
//   role: "user"
// }

// Можно удалять несколько ключей
const publicUser = omit(user, ['password', 'role']);
```
