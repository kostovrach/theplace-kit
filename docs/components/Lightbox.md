# Theplace-kit <br> Lightbox

Компонент-обёртка для интеграции Fancybox, который автоматически инициализирует lightbox для элементов внутри слота.

Используется для подключения функциональности просмотра изображений/галерей (lightbox) без необходимости вручную инициализировать Fancybox в каждом месте.

## Функционал

- Автоматически биндинг Fancybox к элементам с атрибутом `data-fancybox`
- Работает через глобальный инстанс (`$fancybox` из Nuxt)
- Поддерживает кастомизацию через `options`
- Имеет предустановленные стили и конфигурацию:
    - кастомные CSS-переменные
    - упрощённый toolbar (только кнопка закрытия)
    - modern thumbnails
- Реактивно пересоздаёт биндинг при изменении `options`
- Корректно очищает ресурсы при размонтировании

## Props

| Prop      | Тип               | По умолчанию | Описание                     |
| --------- | ----------------- | ------------ | ---------------------------- |
| `options` | `FancyboxOptions` | `undefined`  | Кастомные настройки Fancybox |

## Слоты

| Slot    | Описание                                          |
| ------- | ------------------------------------------------- |
| default | Контент с элементами, содержащими `data-fancybox` |

## Поведение

- При `mounted`:
    - вызывает `Fancybox.bind` для всех элементов внутри контейнера
- При изменении `options`:
    - удаляет предыдущий биндинг (`unbind`)
    - закрывает открытые инстансы (`close`)
    - повторно инициализирует Fancybox
- При `beforeUnmount`:
    - очищает биндинг
    - закрывает Fancybox

## Зависимости

- `@fancyapps/ui` (Fancybox)
- Nuxt plugin (`$fancybox`)

## Пример использования

```vue
<Lightbox>
  <a v-for="(slide, idx) in gallery" :key="idx" :href="slide.src" data-fancybox="gallery">
    <img :src="slide.scr" :alt="slide.title" />
  </a>
</Lightbox>
```
