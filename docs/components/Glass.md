# Glass effect

Набор компонентов для реализации liquid glass через SVG-фильтр.

---

## Glass/mask

SVG-компонент, определяющий фильтр искажения (`feTurbulence` + `feDisplacementMap`), используемый для создания эффекта "жидкого стекла".

Используется как глобальное определение SVG-фильтра, который применяется `Glass/wrapper` через `backdrop-filter`.

### Функционал

- Определяет SVG-фильтр с `id="liquid-glass-distortion"`
- Использует:
    - `feTurbulence` для генерации шума
    - `feDisplacementMap` для искажения изображения
- Проверяет поддержку окружения (через `isChromium`, без влияния на рендер)

### Поведение

- Должен быть подключён один раз на уровне приложения (в app.vue или layout)
- Предоставляет фильтр по `id`, для использования через `url(#liquid-glass-distortion)`

---

## Glass/wrapper

Обёртка для применения визуального жидкого стекла к любому контейнеру.

Используется для стилизации блоков с эффектом стекла (glassmorphism + искажение), например:

- карточки
- модальные окна
- панели

### Функционал

- Поддерживает динамический тег через `component`
- Применяет `backdrop-filter`, включающий:
    - SVG distortion (`url(#liquid-glass-distortion)`)
    - `blur`
    - `saturate`
    - `contrast`
- Имеет fallback:
    - если `backdrop-filter` не поддерживается — используется непрозрачный фон
- Добавляет:
    - полупрозрачный фон
    - внутреннюю и внешнюю тень
    - границу

### Props

| Prop        | Тип      | По умолчанию | Описание                       |
| ----------- | -------- | ------------ | ------------------------------ |
| `component` | `string` | `'div'`      | HTML-тег или компонент-обёртка |

### Слоты

| Slot    | Описание                         |
| ------- | -------------------------------- |
| default | Контент внутри стеклянного блока |

### Поведение

- Рендерит указанный тег (`component`) с классом `liquid-glass`
- Применяет стили эффекта
- Использует SVG-фильтр, определённый в `Glass/mask`
- При отсутствии поддержки `backdrop-filter`:
    - заменяет стеклянный эффект на обычный фон

---

## Пример использования

```vue
<GlassMask />

<GlassWrapper>
  Контент внутри стеклянного блока
</GlassWrapper>

<GlassWrapper component="section">
  Секция с эффектом glass
</GlassWrapper>
```
