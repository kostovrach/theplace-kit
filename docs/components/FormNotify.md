# FormNotify

Набор компонентов для отображения уведомлений в формах: ошибки, информационные подсказки и сообщения об успешных действиях.

---

## FormNotify/Error

Компонент для отображения сообщений об ошибках формы с визуальным выделением и иконкой.

Используется для вывода ошибок валидации или серверных ошибок, связанных с формой или её полями.

### Функционал

- Отображает сообщение с иконкой ошибки
- Поддерживает выравнивание
- Адаптирован для использования как под формой, так и внутри неё

### Props

| Prop        | Тип                  | По умолчанию | Описание                 |
| ----------- | -------------------- | ------------ | ------------------------ |
| `alignment` | `'left' \| 'center'` | `'left'`     | Выравнивание содержимого |

### Слоты

| Slot    | Описание     |
| ------- | ------------ |
| default | Текст ошибки |

---

## FormNotify/Info

Компонент всплывающей информационной подсказки (tooltip-подобный элемент).

Используется для отображения дополнительной информации или подсказок рядом с элементами формы.

### Особенности

- Абсолютное позиционирование относительно родителя
- Кастомизируемая позиция через `top` и `left`
- Не перехватывает события

### Props

| Prop       | Тип                             | По умолчанию                  | Описание                      |
| ---------- | ------------------------------- | ----------------------------- | ----------------------------- |
| `position` | `{ top: string; left: string }` | `{ top: '100%', left: '0%' }` | Позиция относительно родителя |

### Слоты

| Slot    | Описание        |
| ------- | --------------- |
| default | Текст подсказки |

### Поведение

- Позиционируется абсолютно относительно ближайшего `position: relative` родителя
- Всегда отображается поверх контента
- Не влияет на поток документа

---

## FormNotify/Success

Компонент для отображения сообщения об успешном выполнении действия (например, отправка формы).

Используется для информирования пользователя об успешных операциях (submit формы, сохранение данных и т.д.).

### Особенности

- Отображает сообщение с иконкой
- Поддерживает тему отображения (`dark`, `light`) через модификатор класса
- Не содержит логики автоскрытия или управления состоянием (управляется извне)

### Props

| Prop    | Тип                 | По умолчанию | Описание        |
| ------- | ------------------- | ------------ | --------------- |
| `theme` | `'dark' \| 'light'` | `'dark'`     | Визуальная тема |

### Слоты

| Slot    | Описание        |
| ------- | --------------- |
| default | Текст сообщения |

---

## Пример использования

```vue
<FormNotifyError v-if="formErrors.general" && formErrors.general.length>
  {{ formErrors.general }}
</FormNotifyError>

<FormNotifyInfo v-if="formErrors.phone" :position="{ top: '120%', left: '50%' }">
  Данные поле обязательно для заполнения
</FormNotifyInfo>

<FormNotifySuccess v-if="isSubmited">
  Форма успешно отправлена
</FormNotifySuccess>
```
