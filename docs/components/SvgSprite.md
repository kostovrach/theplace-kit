# SvgSprite

Обёртка над компонентом `SvgIcon` для упрощённого использования SVG-иконок через спрайт.

Используется как единая точка доступа к SVG-иконкам в проекте, обеспечивая консистентный API для задания типа, размера и цвета.

## Функционал

- Проксирует пропсы в `SvgIcon`
- Управляет размером через `width` и `height`
- Управляет цветом через inline-стиль (`color`)
- Имеет значения по умолчанию для быстрого использования
- Поддерживает любые иконки, зарегистрированные в спрайте (папка `app/assets/svg`)

## Props

| Prop    | Тип                | По умолчанию     | Описание                     |
| ------- | ------------------ | ---------------- | ---------------------------- |
| `type`  | `string`           | `'arrow'`        | Имя иконки в спрайте         |
| `size`  | `number \| string` | `24`             | Размер иконки (width/height) |
| `color` | `string`           | `'currentColor'` | Цвет иконки                  |

## Пример использования

```vue
<SvgSprite type="common-arrow" />

<SvgSprite type="common-cross" :size="32" />

<SvgSprite type="logo" size="48" color="#FF0000" />
```
