# Theplace-kit <br> UseClock

Composable для реактивного отображения текущего времени с поддержкой часового пояса.

## Назначение

Предоставляет реактивное значение текущего времени, которое автоматически обновляется каждую секунду. Удобен для отображения живых часов в интерфейсе (шапка, футер, дашборды, виджеты).

## Функционал

- Реактивное значение `time` (ref)
- Обновление каждую секунду
- Поддержка любого часового пояса (`Intl` API)
- Поддержка локали
- Очистка интервала при размонтировании компонента
- Формат: `HH:mm:ss` (24-часовой)

## Аргументы

| Параметр     | Тип      | По умолчанию           | Описание                                      |
| ------------ | -------- | ---------------------- | --------------------------------------------- |
| `timezone`   | `string` | `'Europe/Samara'`      | Часовой пояс (IANA timezone)                 |
| `locale`     | `string` | `'ru-RU'`              | Локаль для форматирования времени             |

## Возвращаемое значение

| Поле     | Тип     | Описание                                      |
| -------- | ------- | --------------------------------------------- |
| `time`   | `Ref<string>` | Реактивная строка с текущим временем (`"14:35:22"`) |

## Пример использования

```ts
const { time } = useClock();
// или с параметрами
const { time: moscowTime } = useClock('Europe/Moscow');
const { time: utcTime } = useClock('UTC', 'en-US');
```
