# Theplace-kit <br> useCmsItem

Composable для получения одной сущности из multiple коллекции CMS по `id` с поддержкой SSR-кэширования и загрузки связанных данных.

Используется для получения детализированных данных конкретного элемента коллекции CMS, например:

- статья
- продукт

## Функционал

- Основан на `useFetch` (Nuxt)
- Поддерживает generics (`<T>`) для типизации результата
- Работает с endpoint вида `/api/cms/{collection}/{id}`
- Поддерживает relations (связанные сущности)
- Использует SSR-кэш через `key`
- Возвращает нормализованное поле `item`

## Параметры

| Параметр        | Тип                | Описание                   |
| --------------- | ------------------ | -------------------------- |
| `collection`    | `string`           | Название CMS коллекции     |
| `id`            | `string \| number` | id элемента                |
| `withRelations` | `string[]`         | Список связанных сущностей |
| `opts`          | `object`           | Дополнительные настройки   |

### opts

| Поле           | Тип       | По умолчанию | Описание                                        |
| -------------- | --------- | ------------ | ----------------------------------------------- |
| `resolveFiles` | `boolean` | `true`       | Разрешение файловых связей                      |
| `force`        | `boolean` | `false`      | Принудительная загрузка (влияет на `immediate`) |
| `key`          | `string`  | `auto`       | Кастомный ключ кэширования                      |

## Возвращаемое значение

| Поле      | Тип                      | Описание          |
| --------- | ------------------------ | ----------------- |
| `item`    | `ComputedRef<T \| null>` | Полученный объект |
| `status`  | `AsyncDataRequestStatus` | Статус запроса    |
| `refresh` | `() => Promise<void>`    | Перезапрос данных |

## Поведение

- Формирует query:
    - `relations` → строка через запятую
    - `resolveFiles` → boolean
- Генерирует `key`:
    - зависит от коллекции, id и relations
- Использует `useFetch`:
    - `server: true` (SSR поддержка)
    - `immediate: !opts.force`
- Оборачивает ответ:
    - `data.value.data → item`

## Особенности кэширования

- Уникальный ключ зависит от:
    - коллекции
    - id
    - relations
- Позволяет переиспользовать SSR payload
- Может быть переопределён через `opts.key`

## Отличия от `useCms`

| useCms             | useCmsItem       |
| ------------------ | ---------------- |
| список данных      | один элемент     |
| фильтрация, лимиты | только id        |
| коллекции          | коллекция + item |

## Пример использования

```ts
const { item, status } = await useCmsItem<Article>('articles', 123);
```
